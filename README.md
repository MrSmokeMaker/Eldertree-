# Eldertree – Premium Interactive Family Tree App

## Overview
Eldertree is a modern, cross‑platform family‑tree application built with Flutter.  It lets you **create**, **visualize**, and **share** your family history in a beautiful, interactive interface.  The app works on mobile (iOS & Android) and the web, storing data securely in Supabase.

## Core Features
- **Tree Canvas** – drag‑and‑drop members, view relationships with smooth zoom and pan.
- **Rich Profiles** – photos, biographical details, and voice‑memories for each member.
- **Timeline** – chronological view of events and facts across the whole family.
- **Import / Export** – generate GEDCOM files for genealogy programs (MyHeritage, Ancestry) or a full JSON backup.
- **Push Notifications** – reminders for upcoming birthdays, anniversaries, or new entries.
- **Dark / Light Themes** – material‑3 design with automatic system theme handling.
- **Offline support** – data is cached locally and synced when connectivity returns.

## Getting Started (User Guide)
1. **Install** – download the app from the App Store, Google Play, or open the web version at `https://eldertree.example.com`.
2. **Create a Tree** – tap **New Tree**, give it a name, and start adding members.
3. **Add Details** – tap a member to edit their profile, upload a photo, or record a voice capsule.
4. **Connect Relationships** – drag a line between members to define parent‑child, spouse, or sibling links.
5. **Export** – open the **Export** menu to download a GEDCOM file for genealogy software or a JSON backup for safe‑keeping.
6. **Subscribe** – unlock Premium or Family features via the **Premium** tab in settings.
