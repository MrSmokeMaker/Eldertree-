# Eldertree – премиальное интерактивное генеалогическое приложение

## Описание
Eldertree — это современный кросс‑платформенный сервис, позволяющий создать живую семейную историю с помощью красивого визуального дерева, персонализированных профилей и гибкой аналитики. Приложение работает на iOS, Android и в веб‑браузере, а все данные надёжно хранятся в Supabase.

## Ключевые функции
- **Динамичное дерево** — перетаскивайте членов семьи, масштабируйте и перемещайте полотно в реальном времени.
- **Развернутые профили** — фотографии, биографии, голосовые воспоминания и пользовательские метки.
- **Хронология событий** — интерактивный таймлайн всех дат и событий семьи.
- **Экспорт/Импорт** — GEDCOM‑файлы для внешних генеалогических программ и JSON‑резервные копии.
- **Уведомления** — напоминания о днях рождения, годовщинах и новых записях.
- **Темы Light/Dark** — материал‑3 дизайн, автоматически подстраиваемый под системные настройки.
- **Оффлайн‑режим** — локальное кеширование и синхронная загрузка при восстановлении соединения.
